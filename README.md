
# 🔍 CaseZero — A Cinematic Mystery Game

### Every clue hides a secret.

CaseZero is a browser-based mystery detective game where players investigate a missing prototype, examine clues, question suspects, collect evidence, and attempt to solve the case.

---

## 🎮 About the Project

A valuable prototype mysteriously disappears during a college technology festival. As the lead detective, your mission is to investigate the incident, examine suspects' alibis, collect evidence, and identify the culprit.

Can you uncover the truth behind the missing prototype?

## ✨ Features

- 🌌 Dark cinematic interface with purple accents
- 🔎 Interactive investigation screen
- 🧩 Multiple clue-selection choices
- 📁 Evidence collection section
- 🕵️ Three fictional suspects with different alibis
- 🔍 Interactive suspect investigation
- ⚖️ Final case decision and result messages
- 📱 Responsive styling for smaller screens

## 🛠️ Technologies Used

- **HTML5** — Webpage structure
- **CSS3** — Styling and visual design
- **JavaScript** — Interactive game functionality

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click **Start Investigation** to begin playing.

No additional software or installation is required to run the basic version.
